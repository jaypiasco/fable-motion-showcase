# Fable Motion: Video Demo Showcase

This directory contains the media assets demonstrating the end-to-end execution of the **Fable Motion** multimodal AI video generation pipeline.

## Files
- `FableMotion_demo.mp4`: Full 1080p walkthrough video (~2m 17s, 60fps) demonstrating script generation, character consistency bibles, keyframe rendering, Veo 3.1 motion clips, dynamic word-level karaoke captioning, and the real-time Web Studio dashboard.
- `demo_preview.gif`: Lightweight animated preview for the repository README.
- `demo_poster.jpg`: High-resolution video poster frame.

## Video Playback
You can view the video directly on GitHub or locally using any media player:
```bash
# Play locally via FFplay or default system player
ffplay demo/FableMotion_demo.mp4
```
